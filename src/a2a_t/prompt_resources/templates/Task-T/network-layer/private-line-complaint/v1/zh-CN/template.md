## 任务类型
传输专线业务投诉诊断

## 任务描述
基于[任务对象](#任务对象)、[任务上下文](#任务上下文)进行投诉场景的网络侧故障根因诊断, 达成[任务目标](#任务目标)中定义的投诉诊断目标，按照[预期输出](#预期输出)中定义的结构返回任务处理结果。

## 任务目标
对网络侧故障进行诊断，返回故障根因和修复建议等诊断结果信息。

## 任务对象
{{任务对象}}（必填）

要求：支持传入 专线业务名称/专线业务标识/专线业务接入端口名称，选择其中1种方式来表示专线业务对象
1. 专线业务名称（选填）：网络侧的专线业务名称；样例：SZ_汇聚专线业务_100M_SPN
2. 专线业务标识（选填）：网络侧的专线业务唯一标识；样例：5571d707-5aad-11ea-8629-286ed488cff3
3. 接入端口名称（选填）：业务的接入端口名称，可以是物理端口或者逻辑端口（子接口）
  - 物理端口格式为：网元名称+单板号+单板型号+端口号；样例：P180-SZ-PTN7900-23-TPA1EG24-17
  - 逻辑端口格式为：网元名称+单板号+单板型号+端口号(cvlan=接入vlanid)；样例：P180-SZ-PTN7900-23-TPA1EG24-17(cvlan=100)

## 任务上下文
{{任务上下文}}（必填）

要求：请提供如下信息
1. 投诉分类（必填）：包含"专线中断"和"专线质差"2种场景；样例："专线质差"
2. 问题发生时间（选填）；样例："2026-05-16T08:21:46Z"
3. OSS侧事件流水号（必填）：填写OSS侧的专线业务投诉工单流水号；样例："event-id-20260511-09013"
4. 投诉详情（选填）：可以包含专线用户对于业务投诉的描述，以及OSS侧的预处理信息；样例："从今天早上8点半开始，从SZ访问GZ的响应延迟从平均12ms骤升至320ms，访问GZ机房的核心交易系统非常慢。柜面和手机银行的交易接口频繁报‘连接超时’，正常业务操作要等十几秒甚至半分钟才能返回结果!"

## 预期输出
要求投诉诊断任务的结果包含如下信息：
1. 诊断结果（必填）；取值范围包括：成功、失败
2. 诊断结果详细信息（必填）
3. 修复建议（选填）
4. 故障根因列表（选填）：每个故障根因包含故障根因名称、详细描述、修复建议、故障根因点位置等信息


## 术语解释
1. 专线中断
   - 同义词：private line interruption，业务中断，网络无法连通，业务不通，业务无法访问
2. 专线质差
   - 同义词：private line poor quality，业务卡顿，业务访问超时，业务丢包，业务时延大，业务抖动，业务拥塞，业务体验下滑，业务误码率高，业务光功率异常
